# دفتر (Daftar)

تطبيق سطح مكتب لإدارة مبيعات التقسيط، مبني بلغة Python وواجهة KivyMD.

## التثبيت

```bash
python3 -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## التشغيل

```bash
python main.py
```

عند أول تشغيل يقوم التطبيق تلقائياً بإنشاء قاعدة بيانات SQLite في:
`assets/database/daftar.db` مع كل الجداول اللازمة.

## الخطوط العربية (اختياري لكن موصى به)

لأفضل عرض للنصوص العربية، حمّل خط "Tajawal" (أو أي خط عربي حديث) وضع الملفات:

```
assets/fonts/Tajawal-Regular.ttf
assets/fonts/Tajawal-Bold.ttf
```

نفس الخط يُستخدم أيضًا في تقارير PDF عبر `services/pdf_service.py`.
بدون هذا الخط، سيعمل التطبيق بخط النظام الافتراضي.

## هيكل المشروع

```
main.py                 نقطة الدخول وربط الشاشات
database.py              طبقة قاعدة البيانات (SQLite)
models.py                نماذج البيانات ومنطق التقييم
theme.py                 الألوان والخطوط والثوابت
screens/                 كل شاشة في التطبيق
widgets/                 عناصر واجهة قابلة لإعادة الاستخدام (بطاقات، صفوف)
services/                خدمات: التقارير، PDF، تشكيل النصوص العربية
reports/                 مخرجات الرسوم البيانية وملفات PDF المولّدة
assets/                  الخطوط والأيقونات وقاعدة البيانات
```

## الميزات الرئيسية

- الشاشة الرئيسية: إحصائيات سريعة (عدد العملاء، أقساط اليوم، المتأخرة، المحصلة).
- إدارة العملاء: إضافة / تعديل / حذف / بحث، مع عرض آخر تاريخ سداد وتقييم تلقائي للعميل.
- جدول أقساط لكل عميل مع زر "تم الدفع" يحدث الحالة والتقييم تلقائيًا.
- **معاملات الأصدقاء**: تسجيل عملاء أتوا عن طريق وسيط/صديق، بنفس منطق الأقساط والتقييم،
  مع تقرير مجمّع لكل صديق (عدد العملاء، الإجمالي، المتأخرون).
- الأقساط: عرض أقساط اليوم / الأسبوع / المتأخرة مع بحث.
- التقارير: ملخص شامل + رسوم بيانية (Matplotlib) + تصدير تقرير PDF احترافي.
- دعم الوضع الليلي من شاشة الإعدادات.

## ملاحظات للتطوير المستقبلي

- الكود منظم بمبدأ فصل الطبقات: `database.py` (بيانات) / `models.py` (منطق) /
  `screens` (عرض) / `services` (خدمات مساعدة) - إضافة شاشة أو ميزة جديدة لا يتطلب
  تعديل الطبقات الأخرى.
- كل الجداول تُنشأ تلقائيًا في `Database.create_tables()`، لذلك إضافة جدول جديد
  تكفي فيه إضافة `CREATE TABLE IF NOT EXISTS` هناك.
- منطق التقييم (`models.compute_rating`) معزول ويمكن تحسينه دون لمس أي شاشة.
